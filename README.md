# ARIFAH'S SIMPLE TURTLE RUNAWAY GAME

## How  To Play The Game

1. The player chooses either the Runner or Chaser role.
2. The game starts with a 30-second countdown timer.
3. If the player chooses Runner:
   - The player controls the Runner using the arrow keys.
   - The AI Chaser tries to catch the Runner.
   - The Runner starts with 3 lives.
   - Losing all lives results in a loss.
   - Surviving for 30 seconds results in a win.

4. If the player chooses Chaser:
   - The player controls the Chaser using the arrow keys.
   - The AI Runner attempts to escape.
   - Each successful catch awards 10 points.
   - The Runner respawns at a random location after being caught.
   - Reaching 50 points results in a win.
   - Failing to reach 50 points before time runs out results in a loss.

5. All turtles are restricted within the game boundary.

6. At the end of the game, a message box displays whether the player has won or lost.
